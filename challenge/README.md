# 거너스 챌린지 — 톡방에 올리기까지 내가 할 일

아스날 인사이드 톡방 챌린지 앱. 아래 5단계만 하면 톡방 사람들이 폰에서 바로 씁니다.
전부 무료이고, 한 번만 하면 됩니다. 막히면 그 단계 화면을 캡처해서 보여 주세요.

---

## 1단계. Supabase에 표 만들기 (5분)

아스날맵 만들 때 쓴 Supabase 프로젝트에 같이 해도 됩니다.

1. supabase.com 접속 → 그 프로젝트 열기
2. 왼쪽 메뉴 **SQL Editor** 클릭 → **New query**
3. 이 저장소의 `challenge/supabase/migrations/20261007_01_challenge_init.sql` 파일 내용을 전부 복사해서 붙여넣기
4. **Run** 클릭. 초록색으로 "Success"가 뜨면 끝

두 번 실행해도 망가지지 않습니다. 같은 방법으로 `challenge/supabase/migrations/` 폴더의 나머지 파일(02 → 03 → … → 09)도 번호 순서대로 실행하세요. 새 기능이 나올 때마다 번호가 하나씩 늘고, 빠진 게 있으면 관리 탭 맨 위에 "마이그레이션 필요"라고 떠요.

## 2단계. Supabase에서 값 2개 복사해 두기 (2분)

같은 프로젝트, 왼쪽 맨 아래 톱니바퀴(Settings)에서:

- **프로젝트 URL**: 왼쪽 메뉴 **Data API** (INTEGRATIONS 아래) → 맨 위 **Project URL** 복사. `https://xxxx.supabase.co` 모양.
  → 메모장에 `NEXT_PUBLIC_SUPABASE_URL` 이라고 적고 옆에 붙여넣기
- **service_role 키**: 왼쪽 메뉴 **API Keys** → 위쪽 탭 **"Legacy anon, service_role API keys"** 클릭 → `service_role` 줄 **Reveal** → 복사.
  → `SUPABASE_SERVICE_ROLE_KEY` 로 적어 두기

주의: 첫 탭에 보이는 `sb_publishable_...` 키나 `anon` 키가 아니라 **service_role** 키입니다. 이 키는 톡방에 절대 올리지 마세요.

## 3단계. 알림 열쇠 만들기 (1분)

맥 터미널에서 이 한 줄만 (저장소를 내려받을 필요 없음):

```bash
npx web-push generate-vapid-keys
```

"Ok to proceed? (y)" 가 나오면 `y` 엔터. 결과가 이렇게 나옵니다.

```
Public Key:
BNxxxx...        ← 이 줄이 NEXT_PUBLIC_VAPID_PUBLIC_KEY
Private Key:
xxxx...          ← 이 줄이 VAPID_PRIVATE_KEY
```

두 줄을 메모장에 붙여 두세요. (이 단계를 건너뛰면 알림만 꺼진 채로 나머지는 다 됩니다.)

## 4단계. Vercel에 올리기 (10분)

1. vercel.com 로그인 → **Add New → Project**
2. 이 GitHub 저장소(`znfdusdb-cell/-`) 선택
3. **Root Directory** 에서 **Edit** 누르고 `challenge` 선택 ← 이게 제일 중요
4. **Environment Variables** 에 아래를 하나씩 추가 (이름 / 값)

| 이름 | 값 |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | 2단계에서 복사한 URL |
| `SUPABASE_SERVICE_ROLE_KEY` | 2단계에서 복사한 service_role 키 |
| `SESSION_SECRET` | 아무 긴 문장 (예: 비밀번호 만들듯 30자 이상 아무렇게나) |
| `ADMIN_PASSWORD` | `4581` (비움 계정 첫 비밀번호. 나중에 앱 안에서 바꿀 수 있음) |
| `INVITE_CODE` | (안 넣어도 됨) 넣으면 가입할 때 이 단어를 알아야 가입됨. 누구나 가입하게 하려면 이 줄은 건너뜀 |
| `CRON_SECRET` | 아무 긴 문장 (알림 보내기용. SESSION_SECRET과 다르게) |
| `NEXT_PUBLIC_VAPID_PUBLIC_KEY` | 3단계의 Public Key |
| `VAPID_PRIVATE_KEY` | 3단계의 Private Key |
| `VAPID_SUBJECT` | `mailto:내이메일주소` |

5. **Deploy** 클릭. 1~2분 기다립니다.
6. **톡방에 올릴 주소는 Settings → Domains 에 있는 짧은 주소**(`challenge-xxxx.vercel.app` 처럼 중간에 난수가 없는 것)입니다.
   배포 직후 화면에 뜨는 긴 주소(`challenge-lqr5fvfyb-...`)는 Vercel 로그인을 요구하니 쓰지 마세요.
   짧은 주소도 로그인을 요구하면 **Settings → Deployment Protection → Vercel Authentication** 을 끕니다.
7. 그 주소로 들어가 `비움 / 4581` 로 로그인되면 성공. 아래 탭에 **관리**가 보입니다.

## 5단계. 알림 자동 발송 켜기 (3분, 3단계를 했을 때만)

GitHub 저장소 페이지 → **Settings → Secrets and variables → Actions → New repository secret** 으로 2개 추가:

- `CHALLENGE_URL` : 앱 주소. 4단계 6번의 Vercel Settings → Domains 에 있는 짧은 주소 (예: `https://challenge-xxxx.vercel.app`, 끝에 `/` 없이). 톡방에 올리는 그 주소와 같음
- `CHALLENGE_CRON_SECRET` : 4단계에 넣은 `CRON_SECRET` 과 똑같은 값

이러면 30분마다 자동으로 "점심 인증 시간이에요", "마감 30분 전" 알림이 나갑니다.

### 5단계가 자꾸 실패하거나 알림이 제때 안 오면

- GitHub Actions 에서 `challenge-remind` 가 **HTTP 401** 로 실패하면: GitHub 비밀값 `CHALLENGE_CRON_SECRET` 과 Vercel 환경 변수 `CRON_SECRET` 이 글자 하나까지 같아야 해요(앞뒤 공백·따옴표 없이). 둘 중 하나를 다시 붙여넣고 Vercel 은 Redeploy, GitHub 은 Actions → challenge-remind → **Run workflow** 로 바로 확인.
- GitHub 무료 크론은 바쁠 때 몇 시간씩 밀려요. 점심 시작·마감 30분 전 같은 알림은 제때 못 가요. 정확히 보내려면 Supabase 의 pg_cron 을 쓰세요(0원):
  1. Supabase → **Database → Extensions** 에서 `pg_cron` 과 `pg_net` 을 켠다
  2. SQL Editor 에서 아래를 실행 (주소와 비밀값만 바꿔서)
     ```sql
     select cron.schedule('challenge-remind', '*/5 * * * *', $$
       select net.http_get(
         url := 'https://gunners-challenge.vercel.app/api/cron/remind',
         headers := '{"x-cron-secret": "여기에_CRON_SECRET"}'::jsonb
       );
     $$);
     ```
  3. 5분마다 자동 호출돼요. 끄려면 `select cron.unschedule('challenge-remind');`. 이걸 쓰면 GitHub 쪽은 Settings → Secrets and variables → Actions → Variables 에 `CHALLENGE_REMIND_ENABLED` = `false` 를 넣어 꺼 두면 돼요.

## 6단계(선택). AI 칼로리 경고 켜기 (3분, 0원)

식사 사진을 올릴 때 AI가 사진을 보고 "약 850 kcal" 하고 추정해 줍니다. 챌린지에 정한 기준(기본 한 끼 700 kcal)을 넘으면 경고창이 뜨고, 그래도 올리면 관리 → 신고 판정에 자동으로 올라와서 비움이 인정/불인정을 고릅니다. 키를 안 넣으면 이 기능만 꺼지고 나머지는 그대로예요.

1. https://aistudio.google.com/apikey 접속 (구글 계정) → **Create API key** → 키 복사. 무료 등급이라 톡방 규모(하루 수십 장)면 돈이 안 나갑니다
2. Vercel → 프로젝트 → **Settings → Environment Variables** → `GEMINI_API_KEY` 이름으로 붙여넣고 저장
3. **Deployments** → 맨 위 배포 → ⋯ → **Redeploy**
4. 앱 관리 탭 맨 위에 "AI 칼로리: Gemini 키 있음"이 뜨면 끝. 기준 kcal 는 챌린지 수정 화면에서 바꿉니다(0이면 끔)

Claude로 하고 싶으면 `GEMINI_API_KEY` 대신 `ANTHROPIC_API_KEY`(https://platform.claude.com)를 넣으면 됩니다. 이쪽은 유료라 사진 1장에 약 10원(기본 모델 claude-opus-5-5) 정도 들고, `ANTHROPIC_MODEL=claude-haiku-5-5` 로 바꾸면 1장에 1원 미만입니다. 둘 다 넣으면 Gemini 를 씁니다.

## PC에서도 앱으로 쓰기

Chrome이나 Edge로 주소를 열면 주소창 오른쪽 끝에 **설치 아이콘**(⊕ 또는 모니터 모양)이 뜹니다. 누르면 바탕화면·시작 메뉴에 아이콘이 생기고 따로 창으로 열립니다. 앱 안의 "홈 화면에 아이콘 추가" 상자에서도 설치 버튼이 뜹니다.

## 관리자(비움)가 앱 안에서 할 수 있는 것

- **관리** 탭: 멤버 목록, 경험치 조정, 비밀번호 잊은 사람 초기화, 다른 관리자 지정
- 챌린지 카드 → **수정**: 벌칙(기본 "톡방에 메가커피 아메리카노 쿠폰 쏘기"), 탈락 기준(기본 실패 3번), 인증 시간대, 횟수 바꾸기
- **챌린지 만들기**: 관리자는 레벨 상관없이 바로. 멤버는 Lv.6부터
- 챌린지 상세 → 리더보드에서 "시작 예정"(또는 오늘 시작한) 사람 옆 **관리자: 지금부터 시작** 을 누르면 월요일까지 안 기다리고 바로 시작. 이미 지난 시간대는 세지 않아요(저녁 시간이면 오늘 저녁부터, 다 끝났으면 내일 점심부터). 오늘 이미 실패로 깎인 경험치가 있으면 되돌려 줍니다
- 🧪 **테스트 참여**: 관리 탭 → **모든 챌린지 테스트 참여**(또는 챌린지 상세의 테스트 참여 버튼). 숨김으로 참여해서 시간 제한 없이 사진을 올려 볼 수 있고, 리더보드·남들 갤러리·집계·경험치에서 빠집니다. AI 칼로리 경고와 신고 판정 흐름은 그대로 돌아요. 챌린지 상세에서 **정식 참여로 전환** 가능
- 리더보드에서 **내보내기**: 그 챌린지에서만 빠짐 (챌린지를 만든 사람도 자기 챌린지에서 가능)
- **관리** 탭 → 멤버 펼치기 → **멤버 퇴출**: 계정과 기록이 전부 지워짐 (되돌릴 수 없음)
- 리더보드는 다이어트처럼 시간대가 있는 챌린지면 점심·저녁 칸을 따로 보여줍니다(점심 완료 금색, 저녁 완료 남색, 안 했으면 빨강). 지금 열린(또는 다음) 시간대를 아직 안 한 사람이 빨간 상자로 맨 위에 와서 콕 찌르기 쉽고, 한 사람은 초록 상자로 내려갑니다. 다이어트는 목표 kg와 진행률만 보이고 실제 몸무게는 본인만 봅니다
- 실패 규칙: 실패 1번마다 경험치가 깎이고(식사 −30, 취미 −60), **한 달에** 설정 횟수(기본 3)만큼 실패하면 탈락. 탈락자는 기프티콘 캡처를 올려야 하고, 그 선물은 살아남은 멤버 중 그 챌린지에서 받은 횟수가 가장 적은 사람(같으면 실패 적은 사람, 그래도 같으면 랜덤)에게 "깜짝 선물"로 갑니다(내 정보 → 선물함). 한 사람이 계속 받지 않게 골고루. 올린 뒤 "다시 도전"(다음 월요일부터) 또는 "그만하기"를 고릅니다
- 중간 이탈 방지: 시작한 챌린지는 탈락 전까지 그만둘 수 없어요(시작 전엔 가능). 탈락 후에도 기프티콘을 올리기 전엔 못 나갑니다
- 🎁 **벌칙 현황**(챌린지 상세, 개설자·관리자만): 탈락했는데 기프티콘을 안 올린 사람, 올린 기프티콘이 누구에게 갔고 열어봤는지. 기프티콘 이미지는 받은 사람만 볼 수 있어요
- 월이 바뀌면 첫 접속 때 지난달 결산 팝업(성공률 %, 칭찬). 탈락 없이 넘긴 달은 완주 보너스 +100 XP
- 내 정보 → **개발자에게 문의**: 오류 화면 사진과 함께 채팅으로 보냄. 비움은 관리 → 문의 목록에서 답하고 **해결 완료**를 누르면 목록에서 사라짐
- 갤러리 인증 카드의 💬 **댓글**: 같은 챌린지 멤버끼리 사진에 댓글(200자). 내 댓글은 삭제, 비움은 아무 댓글이나 삭제. 댓글이 달리면 사진 주인에게 알림. 챌린지 수정 화면의 **인증 사진에 댓글 허용** 체크를 끄면 그 챌린지에선 댓글 버튼이 사라짐(기존 댓글은 남고 다시 켜면 보임)
- 🤖 **AI 칼로리 경고**(6단계를 했을 때): 다이어트 사진을 올리면 AI가 칼로리를 추정해 사진에 "약 N kcal"가 붙고, 기준을 넘으면 올리기 전에 경고창. 기준은 사람마다 달라요: 참여할 때 넣은 키·체중·나이로 기초대사량(Mifflin-St Jeor)을 구하고, 목표 감량·남은 기간에 필요한 하루 결손을 빼서 하루 섭취 목표(여 1,200 / 남 1,500 아래로는 안 내려감)가 그날 예산. 끼니별로 균등 배분하지 않고 하루 합계로 봐요: 점심에 900을 먹었으면 저녁 한도는 예산−900. 아침·간식을 먹는다고 고르면 그 몫만큼 예산에서 미리 빼요. 예산을 넘기는 끼니에서 경고. 체중을 기록하면 매일 다시 계산. 키를 안 넣은 사람은 챌린지 기본값(수정 → 기본 기준, 700). "그대로 올리기"를 누르면 관리 → 신고 판정에 자동으로 올라오고 비움 폰에 알림. 불인정하면 그 시간대는 실패, 인정(기각)하면 그대로
- 갤러리 인증 카드의 **신고**: 같은 챌린지 멤버 누구나 사유를 골라 신고. 비움은 관리 → 신고 판정에서 사진을 보고 **인정(기각)** 또는 **불인정**. 불인정이면 그 인증은 집계에서 빠져 그 시간대가 실패가 되고 받은 경험치는 회수, 갤러리엔 "불인정" 표시
- 갤러리 인증 카드의 🔥 **응원**: 같은 챌린지 멤버끼리 좋아요. 처음 응원하면 주인에게 알림. 받은 응원 합이 내 정보 캐릭터 옆·홈·리더보드에 표시
- 참여 독려: 리더보드에서 아직 인증 안 한 사람 **콕 찌르기**(하루 1번, 그 사람 폰에 알림), 알림 문구에 "이미 N명이 올렸어요", 알림을 누르면 바로 카메라가 열림

## (개발자용) 구조 메모

Next.js 16 · Tailwind 4 · supabase-js(service role 서버 전용) · web-push. 로컬은 `npm run dev` (환경변수 없으면 메모리 모드).
`src/lib/game.ts` 경험치·레벨·판정 엔진, `src/lib/repo/` 저장소(memory/supabase), `src/app/actions.ts` 서버 액션,
`src/app/api/checkin` 사진 인증, `src/app/api/cron/remind` 알림, `src/components/Character.tsx` 레벨별 캐릭터, `public/sw.js` 서비스 워커.
판정 규칙: 서버 KST 기준. 집계 시작은 월요일(월요일 첫 슬롯 전 가입이면 당일, 아니면 다음 월요일; 관리자가 `start_date`로 덮어쓸 수 있음). 시작 전엔 인증 불가, 전날 20시·당일 8시에 알림.
다이어트는 앱 촬영만(날짜·시각 새김), 취미는 촬영·앨범·녹음·링크(`media_type`, 참여 때 취미 글자로 추천 → `goal.methods`). 실패가 `max_fails`에 닿으면 탈락(계산값), 벌칙 `penalty`. 체중은 `ch_weight_logs`(본인만). 사진은 서명 URL + 저장 방지(길게 누르기·드래그 차단). 연속·실패는 저장하지 않고 기록에서 계산.
